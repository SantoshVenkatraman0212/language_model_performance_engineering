# Language Model Performance Engineering
### This repo depicts hands-on exploration of compute and memory optimized implementations of various tensor operations such as attention, softmax, and tensor operations that form the core of modern language model training, and inference. The main purpose of this repo is :

``Understanding naive implementation bottlenecks -> Identifying compute, memory & numerical bottlenecks-> Implementation of optimized approaches -> Comparing results``

### The prime focus here is to analyze why naive computations can cause numeric overflow, excessive VRAM consumption, and High Bandwidth Memory (HBM) demand and how do optimizations offer both speed and reduce memory footprint. The key here is to understand how optimizations address these problems while also keeping in mind the tradeoffs.
